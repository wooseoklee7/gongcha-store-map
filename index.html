카카오맵 JavaScript 키를 처음 한 번 입력하면 이 브라우저에 저장되며, 다음 접속부터 자동으로 지도를 시작합니다.

처음 한 번만 설정
Kakao Developers에서 카카오맵 API 사용 ON → JavaScript 키 확인 → 해당 키의 JavaScript SDK 도메인에 실행 주소를 등록하세요.
로컬 파일을 직접 열면 file:// 도메인을, 웹서버로 실행하면 http://localhost:8000 등을 등록해야 합니다.
지도는 열리는데 주소검색만 실패한다면 키 종류가 JavaScript 키인지와 카카오맵 API 사용 설정을 다시 확인하세요.
